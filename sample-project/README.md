# Sample Demonstration Project

This folder contains synthetic demonstration files used to test and showcase **CloudGuard**.

> **IMPORTANT NOTICE:** All credentials and tokens in this folder are completely synthetic, inactive test placeholders. None of them represent active, usable credentials for any cloud provider or third-party service.

### Contained Patterns:
- **AWS Access Key ID:** `AKIAIOSFODNN7EXAMPLE` (High severity)
- **AWS Secret Access Key:** `wJalrX...` (Critical severity)
- **GitHub PAT:** `ghp_FakeExample...` (Critical severity)
- **Database Connection URI with embedded password:** `postgresql://dbadmin:SuperSecretDemoPass987!...` (Critical severity)
- **Hardcoded Database Password:** `password = HardcodedSecretPassword456!` (High severity)
- **JWT Token & Secret:** `super_secret_jwt_signing_key_sample_789` (Medium severity)
- **Benign Entities (Not flagged as high severity secrets):** UUIDs, Git commit SHA1 hashes, URLs, constants.
